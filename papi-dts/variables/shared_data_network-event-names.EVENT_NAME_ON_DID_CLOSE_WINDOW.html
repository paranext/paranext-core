    Variable EVENT_NAME_ON_DID_CLOSE_WINDOWConst Experimental

    EVENT_NAME_ON_DID_CLOSE_WINDOW: "platform:onDidCloseWindow" = 'platform:onDidCloseWindow'

    Name of the platform-internal network event the main process emits when a window closes. The payload is the closed window's Electron window id.

    The main process owns window-lifecycle truth, so it is the only emitter — this is a single-source event and deliberately absent from MULTI_SOURCE_EVENT_NAMES. It is a plain string rather than a NetworkEvents declaration because it is core plumbing between the main process and the renderer service hosts, not part of the @papi/* surface.

    Renderers need this because a closing window tears its RPC connection down without disposing the network objects it hosted: nothing emits object:onDidDisposeNetworkObject on a socket close, so app-global services hosted by one window (the theme engine, the scroll group service) have no other signal that their host went away.
