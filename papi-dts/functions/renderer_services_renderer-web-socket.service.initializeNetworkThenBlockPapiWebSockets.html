    Function initializeNetworkThenBlockPapiWebSockets

    • initializeNetworkThenBlockPapiWebSockets(
          initialize: () => Promise<void>,
      ): Promise<void>

      Runs initialize, then blocks web views from the PAPI network whether it resolved or rejected, so a renderer that failed to connect does not keep running with extension sandboxing off.

      The block cannot run before initialize settles: without an Electron bridge, the renderer's own connection to main is a PapiRendererWebSocket to the PAPI port (see web-socket.factory.ts). Until it settles (at most about 10 s, the connect timeout) web views are not blocked; none can exist yet, because the web view service starts only after this call in index.tsx.

      Parameters

      • initialize: () => Promise<void>

        Starts the renderer's network service

      Returns Promise<void>

      Throws

      Whatever initialize threw or rejected with, after blocking
