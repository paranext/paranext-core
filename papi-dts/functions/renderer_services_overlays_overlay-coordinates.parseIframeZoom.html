    Function parseIframeZoom

    • parseIframeZoom(iframe: undefined | null | HTMLIFrameElement): number
      Experimental

      Parses the CSS zoom inline on an iframe element. Anything that is not a positive finite number — including the empty string written to clear the zoom, or no iframe at all — means unscaled.

      Exported so getWebViewIframeZoom and the content zoom service's own iframe-zoom fallback (which reads its iframe through its own test-only seam, not getWebViewIframe) share one parse instead of drifting apart.

      This function is unstable and may change or disappear without notice

      Parameters

      • iframe: undefined | null | HTMLIFrameElement

      Returns number
