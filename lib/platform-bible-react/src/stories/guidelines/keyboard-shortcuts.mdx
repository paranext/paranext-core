# Keyboard shortcuts

Keyboard shortcuts are documented in one place: the
[Reference → Keyboard shortcuts](https://paranext.github.io/paranext-core/paranext-core-storybook/?path=/docs/reference-keyboard-shortcuts--docs)
page in the main Platform.Bible Storybook (`src/stories/keyboard-shortcuts.mdx`). It has both:

- **The conventions** — how to write a shortcut for each OS (macOS symbols with no separator;
  Windows/Linux words joined with `+`), the preferred representation of every key, modifier order,
  and how to render a shortcut with `ShortcutKeys`.
- **The catalog** — every shortcut in the application, including the ones defined in this library,
  with where each is handled in code, its conflicts, and how it compares with Paratext 9.

For how shortcuts appear in tooltips, see
[Tooltips → Keyboard shortcuts in tooltips](?path=/docs/guidelines-tooltips--docs#keyboard-shortcuts-in-tooltips).

## Detecting the platform

Moved to
[Reference → Keyboard shortcuts → Detecting the platform](https://paranext.github.io/paranext-core/paranext-core-storybook/?path=/docs/reference-keyboard-shortcuts--docs#detecting-the-platform)
in the main Platform.Bible Storybook. In short: pick the hint for the user's OS with `isMacOs()`
(or `isWindows()`), and render it with `ShortcutKeys` from `platform-bible-react/experimental`.
